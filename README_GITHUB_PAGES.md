# HUFT Sales Dashboard — GitHub Pages (Static)

This is a static HTML dashboard. It does not require a backend or login page.

## Publish using GitHub Pages
1. Open your repository: https://github.com/22chandulalbanoth-cell/HUFT-sales-dashboard
2. Back up/download the current repository before replacing files.
3. Upload `index.html` to the repository root (same level as README.md), replacing the old `index.html` if prompted.
4. Click **Commit changes**.
5. In GitHub, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a few minutes and open the published Pages URL shown in Settings → Pages.

## Important
- This is a static site: it has no server-side login, database, or backend.
- Anyone who can access the published URL can open the dashboard. Do not publish customer-identifiable or confidential sales data inside the HTML or any public repository.
- Uploaded workbook processing/storage happens in the browser only if the dashboard code implements it. Browser storage is local to each browser/device and can be removed by clearing site data.
- Use a private repository to protect source code, but note that GitHub Pages access is generally public for public sites and private-site access depends on GitHub plan/org settings.
